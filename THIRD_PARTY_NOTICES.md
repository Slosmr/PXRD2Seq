# Third-party notices

The construction scripts use NumPy, pandas, pymatgen, SciPy, tqdm, and the
Materials Project API client. These packages are installed as dependencies;
their source code is not vendored in this repository. Their own license and
attribution notices continue to apply.

Input data originate from Materials Project, COD, AMCSD, and RRUFF. See
[data sources](docs/DATA_SOURCES.md). The repository includes no original database
archive, downloaded paper, or third-party model weights.

AlphaDiffract is one of the external references selected for this work.

A project-level code license has not been declared in this preliminary snapshot.
No license is inferred from the license of any dependency or input database.
