# Release plan

## Preliminary submission release

Included now:

- PXRD2Seq project overview and manuscript metadata.
- Dataset definitions, aggregate study counts, source information, and limitations.
- MP/COD/AMCSD structure construction, filtering, reconstruction, and materialization.
- RRUFF parsing, base preparation, classification selection, and regression proxy.
- Configuration examples and pinned direct dependencies.

## Planned after acceptance or publication

- PXRD2Seq model definition, tokenizer, training, and inference commands.
- Shared preprocessing and online augmentation used by the model pipeline.
- Retrained baselines and the common evaluation protocol.
- Symmetry-prefix, output-order, compatibility, and lattice-geometry analyses.
- Exact study split/cohort manifests and checkpoints, with source and version information.
- Final RRUFF model-input assembly using the base grid and strict cohort identifiers.
- Processed data artifacts where redistribution is appropriate.
